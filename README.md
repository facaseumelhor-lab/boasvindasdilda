# Portal de Boas-Vindas & Manual de Sinistros — Marisa Dilda Seguros

Este repositório contém a página web responsiva de Boas-Vindas e o Manual de Sinistros da **Marisa Dilda Seguros**. Ele serve como um guia operacional de transição para transportadoras e segurados.

## 🚀 Funcionalidades do Portal

- **Diretório de Canais**: Contatos rápidos para o setor Operacional, Financeiro e o time de Sinistros.
- **CTO 24h (Central de Tratativa de Ocorrências)**: Linha de emergência integrada e acionamento direto do Mão Amiga e Pronta Resposta.
- **Guias de Sinistros**: Checklists operacionais rápidos para sinistros de Carga (RCTR-C, RCF-DC, RCTR-VI) e Terceiros (RC-V).
- **Design Moderno**: Interface responsiva desenvolvida com Tailwind CSS, ícones interativos e suporte para impressão otimizada em PDF.

## 🛠️ Tecnologias Utilizadas

- **HTML5** & **Tailwind CSS** (via CDN)
- **Iconify** (Ícones dinâmicos)
- **Vanilla JavaScript** (Interações de menu, FAQ e widget flutuante)
